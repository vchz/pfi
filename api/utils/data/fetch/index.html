    fetch(url)

    Fetch a .h5ad or .h5ad.gz file into PFI_DATA_FOLDER.

    Parameters:

    • url (str) –

      Remote URL ending with .h5ad or .h5ad.gz.

    Returns:

    • local_path ( str ) –

      Local file path under PFI_DATA_FOLDER.

    Raises:

    • ValueError –

      If url does not end with .h5ad or .h5ad.gz.
